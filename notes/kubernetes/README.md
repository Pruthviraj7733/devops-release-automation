# Kubernetes Study Notes

Structured study material for Kubernetes theory, practical commands, self-assessment, and DevOps interviews.

> These are **learning notes**, separate from the production-inspired CI/CD project configuration. They do not indicate that every example has been deployed or tested in the project.

## How to use

1. Read the **Theory** section and rewrite the core concepts in your notebook.
2. Run **Hands-on** commands on an available practice cluster (not the deleted project EKS cluster).
3. Complete the **Practice Tasks** without looking at the answers.
4. Rehearse the **Interview Answer** in your own words.
